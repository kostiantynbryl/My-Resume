# NORVEXA Portfolio — Design Freeze

Version: **1.2 — Proof & Conversion**

The visual system is considered stable after v1.2. Future releases should update content, projects, screenshots, evidence and accessibility fixes without redesigning the core experience unless there is a clear product reason.

## Frozen foundations

- Graphite / near-black base with restrained cyan accent.
- Editorial technology layout with strong whitespace and thin borders.
- Multi-page architecture: Home, Work, Experience, Case Studies, About, Now, Contact, Ecosystem and audience-specific views.
- System font stack for first-render performance and predictable multilingual layout.
- NORVEXA logo and wordmark in the global header.
- Four-language support: EN / PL / RU / UA.
- Recruiter dock with CV, Telegram and email access.
- Evidence-first project pages: Problem → Role → Built → Result → Stack → Evidence.
- Real screenshots must be labelled as real; concept visuals must never be represented as captured product UI.
- Lighthouse gate: Performance ≥ 95, Accessibility ≥ 95, Best Practices ≥ 95, SEO ≥ 95.

## Allowed changes after freeze

- Add or update projects.
- Add real product screenshots.
- Add verified recommendations/references.
- Update experience and measurable outcomes.
- Improve copy and translations.
- Fix responsive, accessibility, performance or browser issues.
- Activate a custom domain or privacy-friendly analytics endpoint.

## Changes that require an explicit v2.0 decision

- Replacing the design language.
- Returning to a single-page portfolio.
- Introducing a frontend framework solely for visual effects.
- Adding persistent user tracking, advertising or unnecessary third-party SDKs.
- Replacing evidence-first project structure with decorative marketing-only pages.

## Rule

**Evidence before decoration. Clarity before novelty.**
